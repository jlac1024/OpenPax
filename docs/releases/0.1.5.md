A small update to the first release of OpenPax, an open-source engine for Pax Imperia: Eminent Domain. OpenPax comes with **none of the game**: you need your own copy from [GOG](https://www.gog.com).

This is an early release: expect rough edges, and please report what you find.

## What's new in 0.1.5

- **A Windows installer.** `OpenPax-0.1.5-win-x64-setup.exe` installs OpenPax for you, with no admin rights needed: a Start menu entry, a desktop shortcut if you want one, and an uninstaller in Windows' Apps list. The zip is still there if you prefer it. The game keeps updating itself either way.
- **OpenPax has its own icon:** a gold star in an orbit, on the program, the window, the installer, the shortcuts and the Mac app.
- **Fixed: the update offer's colors.** Over the main menu, the update popup came out pink with its buttons missing. It is now its own dialog, drawn the same as Options. (If 0.1.3 or 0.1.4 shows you the broken one, press Enter to update: the hidden button is YES.)
- **The mods list shows what is on at a glance:** a green light and green name for each mod turned on, a red light for those off. The same in a hosted lobby room.

If you have 0.1.3 or 0.1.4, the game offers this update itself.

Everything else is as in [0.1.4](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.4) and [0.1.3](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.3); [0.1.0](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.0)'s notes cover what's in OpenPax.

## Getting started

1. Download the bundle for your system below and unpack it.
   - **Windows:** run `OpenPax-0.1.5-win-x64-setup.exe`, or unzip `OpenPax-0.1.5-win-x64.zip` (the whole folder) and run `openpax.exe`. Windows warns about an unsigned program: click **More info**, then **Run anyway**.
   - **Linux:** `OpenPax-0.1.5-linux-x64.tar.gz`, then run `./openpax`.
   - **macOS (Apple Silicon):** `OpenPax-0.1.5-osx-arm64.tar.gz`. Run `./prepare_mac.sh` once from the unpacked folder, then open `OpenPax.app`.
2. On first start, point OpenPax at your copy of the game: an installed copy, or GOG's **offline backup installer** (`setup_pax_imperia_2.0.0.12.exe`). The small GOG Galaxy installer holds none of the game.
3. The import converts the game once, into your user folder (a few minutes). Then the game starts.
