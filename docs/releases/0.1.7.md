A small update to the first release of OpenPax, an open-source engine for Pax Imperia: Eminent Domain. OpenPax comes with **none of the game**: you need your own copy from [GOG](https://www.gog.com).

This is an early release: expect rough edges, and please report what you find.

## What's new in 0.1.7

- **Linux packages.** Besides the tarball, Linux now has a `.deb` (Debian, Ubuntu, Mint and the like) and a Flatpak (any distribution). Each adds OpenPax to the menu with its icon. These are updated by installing the new package, so the game tells you when one is out but does not update itself.
- **Species selection animates as in the original.** Picking another species now closes the open figure and sends it back into its tube before the next one comes out, with each step's sound, and the tubes beside it no longer stay drawn half over the empty spot.
- **Bug fixes in one go.** On its first start, OpenPax asks whether to turn on all its fixes to the original game's bugs (ships given to the computer never reaching it, trades of over 21 ships losing some, fast shots missing planets and more). Your answer is kept, and each fix can still be turned on or off in Options, GAME.
- **No public lobby for now.** The multiplayer menu offers LAN and Private Lobby only; earlier releases pointed PUBLIC LOBBY at an address that was never a real lobby. Anyone running their own public lobby can name it in `config.json`, and the choice comes back.
- **The bridge's pointer stays right.** After a popup over the bridge closed, the pointer stayed the popup's arrow, which came out pink and striped in the bridge's colors.
- **A sky for the tall sector panel.** In a tall window the Sector Display's planet panel used to repeat the same few stars all the way down. It now has its own stars and nebula under the same purple grid, and the metal frame beside it runs smooth instead of in steps.
- **Tooltips on the economy and planet screens.** Rest the pointer on a budget line, a planet's figure, CP Subsidy, the plan or the orbitals on the Domestic Policy screen (F5) or a planet's surface (F7) to see what it is for.
- **Volume in the menu's Options.** A new SOUND tab has master, music, sound effect and voice volumes. (GAMEPLAY is now GAME, to fit.)
- **The game keeps running in the background.** It no longer freezes when its window loses focus. To pause like the original did, turn on **Pause while in the background** under Options, GAME. Network games never pause.

If you have 0.1.3 or later, the game offers this update itself.

Everything else is as in [0.1.6](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.6); [0.1.0](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.0)'s notes cover what's in OpenPax.

## Getting started

1. Download the bundle for your system below.
   - **Windows:** run `OpenPax-0.1.7-win-x64-setup.exe`, or unzip `OpenPax-0.1.7-win-x64.zip` (the whole folder) and run `openpax.exe`. Windows warns about an unsigned program: click **More info**, then **Run anyway**.
   - **Linux:** any one of these:
     - `openpax_0.1.7_amd64.deb`: install it with `sudo apt install ./openpax_0.1.7_amd64.deb`, then start OpenPax from the menu or run `openpax`.
     - `OpenPax-0.1.7-linux-x64.flatpak`: install it with `flatpak install --user OpenPax-0.1.7-linux-x64.flatpak` (it fetches the freedesktop runtime from Flathub), then start OpenPax from the menu.
     - `OpenPax-0.1.7-linux-x64.tar.gz`: unpack it and run `./openpax`. This one updates itself.
   - **macOS (Apple Silicon):** `OpenPax-0.1.7-osx-arm64.tar.gz`. Run `./prepare_mac.sh` once from the unpacked folder, then open `OpenPax.app`.
2. On first start, point OpenPax at your copy of the game: an installed copy, or GOG's **offline backup installer** (`setup_pax_imperia_2.0.0.12.exe`). The small GOG Galaxy installer holds none of the game. The Flatpak can see your Downloads folder and `~/GOG Games` directly; for anywhere else, pick the folder or file in the file picker.
3. The import converts the game once, into your user folder (a few minutes). Then the game starts.
