A small update to the first release of OpenPax, an open-source engine for Pax Imperia: Eminent Domain. OpenPax comes with **none of the game**: you need your own copy from [GOG](https://www.gog.com).

This is an early release: expect rough edges, and please report what you find.

## What's new in 0.1.2

- **Fixed: on Windows, the import opened a console window for each movie** it converted. The movie converter now runs hidden inside the import, and any errors it reports still go to `openpax.log`.

0.1.1 fixed a crash when pressing IMPORT and added crash reports: if OpenPax stops unexpectedly, it says why and writes `crash.log` and `openpax.log` to your user folder (`%APPDATA%\OpenPax\OpenPax\` on Windows). Everything else is as in [0.1.0](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.0), whose notes cover what's in OpenPax.

## Getting started

1. Download the bundle for your system below and unpack it.
   - **Windows:** `OpenPax-0.1.2-win-x64.zip`. Unzip the whole folder, then run `openpax.exe`. Windows warns about an unsigned program: click **More info**, then **Run anyway**.
   - **Linux:** `OpenPax-0.1.2-linux-x64.tar.gz`, then run `./openpax`.
   - **macOS (Apple Silicon):** `OpenPax-0.1.2-osx-arm64.tar.gz`. Run `./prepare_mac.sh` once from the unpacked folder, then open `OpenPax.app`.
2. On first start, point OpenPax at your copy of the game: an installed copy, or GOG's **offline backup installer** (`setup_pax_imperia_2.0.0.12.exe`). The small GOG Galaxy installer holds none of the game.
3. The import converts the game once, into your user folder (a few minutes). Then the game starts.
