# The GOG build

What the GOG release contains, where each part came from, and what GOG
changed. The full per-file list with sizes and sha256 hashes is generated by
`tools/catalog.py` into `build/catalog/gog-files.toml`; it stays out of git
because it describes the private install.

## Version

- GOG product id 1434378430, Galaxy package `galaxy_pax_imperia_2.0.0.12`
  (from `goggame-galaxyFileList.ini`). We call this "GOG build 2.0.0.12".
- `Pax Imperia.exe`: PE32, i386, GUI subsystem, image base,
  entry, no relocations. Linker 5.10 (Visual C++ 5.0). PE
  timestamp 1998-06-10 12:00:12, the same day as the 1.072 update package,
  so this is the 1.072 executable.
- The executable carries an Authenticode signature from GOG Limited
  (DigiCert). The original would not have had one, so GOG at least re-signed
  it. The code changes are listed under "Executable changes" below.
- Source file names are embedded in assert strings (`D:\Pax2\Source\*.cpp`),
  which gives a module list: Universe, Empire, Planet, Fleet, Ship, combat
  (CombatShip, CombatWeapon, CombatFighter, CombatMine, CombatOrbital),
  ResearchMan, EspionageMan, the AI_* files, NetMan, and one file per
  window.

## How GOG made the game run

- **Music.** The game plays CD audio through Miles' redbook calls
  (`AIL_redbook_*`), which go to `winmm` MCI underneath. GOG's `winmm.dll`
  (built 2015, MinGW) forwards everything to the system winmm except the
  CD audio calls, which it serves from `MUSIC/TrackNN.ogg` through
  libvorbisfile. Track 01 was the data track, hence numbering from 02.
- **Video.** The executable plays Smacker files through `Smackw32.dll`
  (Smacker 3.0j, RAD, 1997) with sound through Miles. GOG replaced the
  `.smk` files. The DVD edition's MPEG2 path is not in this executable;
  the movies it names are `Pax2.smk`, `Mix_LOGOS.smk`, `Colonize.smk`,
  `Vacuum_Colon.smk`, `First Contact.smk`, `OtherPlayerElim.smk`,
  `PlayerVictory.smk`, `DefeatMovie.smk`, `Pax2Credits.smk`. The port
  converts them to MP4 at import (`decisions.md`), not MPEG2.
- **Compatibility shim.** `goggame.sdb` is a Windows application
  compatibility database that applies `IgnoreAltTab` to `Pax Imperia.exe`.
- **Disc check and music gate.** Patched in the executable; see below.

## Executable changes

The 1.072 update package (InstallShield PackageForTheWeb, unpacked with
unshield into `build/patch-1072/`) contains the retail 1.072
`Pax Imperia.exe`, 879,104 bytes. The GOG executable is that file plus a
7,248 byte Authenticode signature appended at the end. Of the common bytes,
16 differ:

| Where (VA) | Bytes | Original | GOG | Effect |
|---|---|---|---|---|
| PE header | 7 | | | Checksum and security directory entry, from signing |
| | 1 | `cmp eax, 5` | `cmp eax, 3` | The disc check scans drives with `GetDriveTypeA`. It looked for `DRIVE_CDROM` (5); GOG makes it look for `DRIVE_FIXED` (3). |
| | 2 | `jne` | `nop nop` | Inside the C runtime's `_fsopen`, called only through `fopen`. `fopen` has exactly one caller, the disc check's `fopen(path, "rb")`. GOG makes it return a stream without opening any file, so the check passes on the first fixed drive. The stream is closed straight away and never read. That drive letter is then remembered as the "CD drive" (byte). |
| | 6 | `jne` (skip) | 6 x `nop` | Start of a function called from about ten windows. It returns early when the byte is set. That flag starts at 1 and is cleared only when a CD-ROM drive is found at startup. GOG removes the check so the function runs without a CD drive. This is the CD audio (redbook) control; the CD audio thread starts. GOG's `winmm.dll` then serves it from the Ogg files. |

None of the changes touch game rules. The port has no disc check and
plays music from files, so it matches GOG behavior here without copying
any of it.

The 1.072 package's DLLs and `Data/` tables are byte-identical to the GOG
install. Its `SpecData` and `Prefdata` entries did not extract; GOG
replaced `PrefData` anyway and ships `SpecData` empty.

## Runtime and libraries

- Graphics: `DirectDrawCreate` only. No Direct3D. 256 color palettes
  (`SetSystemPaletteUse`, `PalData`).
- Timing: `timeGetTime` is the only winmm import.
- Sound: Miles Sound System 3.6B (`AIL_quick_*` for samples, redbook for music).
- Networking, three stacks:
  - WinSock 1.1 by ordinal: TCP (`listen`, `accept`, `connect`, `send`,
    `recv`) and UDP (`sendto`, `recvfrom`), plus `gethostbyname` and `select`.
  - Mplayer online service hooks (`MPIPX_*`, `MPlayerVersion`,
    `MPSynchronizeGameTime`), loaded at run time.
  - COMM-DRV serial and modem library (`Cdrvdl32.dll` link layer,
    `Cdrvhf32.dll` modem and port functions), used by `ModemHostWin` and
    `ModemJoinWin`.
- Threads, events and critical sections are used, so some work runs off the
  main thread. Which work, and whether it touches simulation state, matters
  for determinism and is still to be checked.
