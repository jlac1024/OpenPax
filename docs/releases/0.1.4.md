A small update to the first release of OpenPax, an open-source engine for Pax Imperia: Eminent Domain. OpenPax comes with **none of the game**: you need your own copy from [GOG](https://www.gog.com).

This is an early release: expect rough edges, and please report what you find.

## What's new in 0.1.4

- **Smaller windows keep the game's own shape.** In a window under twice the original size (a 1366x768 laptop screen, say), the screens now fill the window in their original 4:3 shape, with starfield beside them, instead of spreading wide and small. From twice the original size up they still widen as before.

If you have 0.1.3, the game offers this update itself the next time it starts.

Everything else is as in [0.1.3](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.3): the game updates itself from GitHub, remembers its window, and has a tidier folder; see its notes and [0.1.0](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.0)'s for what's in OpenPax.

## Getting started

1. Download the bundle for your system below and unpack it.
   - **Windows:** `OpenPax-0.1.4-win-x64.zip`. Unzip the whole folder, then run `openpax.exe`. Windows warns about an unsigned program: click **More info**, then **Run anyway**.
   - **Linux:** `OpenPax-0.1.4-linux-x64.tar.gz`, then run `./openpax`.
   - **macOS (Apple Silicon):** `OpenPax-0.1.4-osx-arm64.tar.gz`. Run `./prepare_mac.sh` once from the unpacked folder, then open `OpenPax.app`.
2. On first start, point OpenPax at your copy of the game: an installed copy, or GOG's **offline backup installer** (`setup_pax_imperia_2.0.0.12.exe`). The small GOG Galaxy installer holds none of the game.
3. The import converts the game once, into your user folder (a few minutes). Then the game starts.
