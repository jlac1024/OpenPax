A small update to OpenPax, an open-source engine for Pax Imperia: Eminent Domain. OpenPax comes with **none of the game**: you need your own copy from [GOG](https://www.gog.com).

This is an early release: expect rough edges, and please report what you find.

## What's new in 0.1.9

- **The Flatpak updates itself from the game.** When a new version is out, UPDATE installs it through Flatpak, as the tarball and Windows versions already update themselves, and the game restarts into it. The first time, your system asks whether OpenPax may update itself. If it cannot, the game says so; update through your software center or `flatpak update` instead.

- **Updates installed while you play.** When your software center (or `flatpak update`, or `apt upgrade`) installs a new OpenPax while the game is running, the main menu offers to restart into it.

- **Fixes:** the bridge's pointer no longer turns pink when it passes over the star map; in a tall window the Sector Display's build panel no longer repeats its BUILD SHIP button's outline; in a wide window the lamp's message history widens with the top bar and reaches the lamp.

If you installed the Flatpak or the .deb from 0.1.8, this version comes to you through your system's updates. Copies from 0.1.7's packages need this one installed by hand, once.

Everything else is as in [0.1.8](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.8); [0.1.0](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.0)'s notes cover what's in OpenPax.

## Getting started

1. Download the bundle for your system below.
   - **Windows:** run `OpenPax-0.1.9-win-x64-setup.exe`, or unzip `OpenPax-0.1.9-win-x64.zip` (the whole folder) and run `openpax.exe`. Windows warns about an unsigned program: click **More info**, then **Run anyway**.
   - **Linux:** any one of these:
     - `openpax_0.1.9_amd64.deb`: install it with `sudo apt install ./openpax_0.1.9_amd64.deb`, then start OpenPax from the menu or run `openpax`. Updates come with your system's updates.
     - `OpenPax-0.1.9-linux-x64.flatpak`: install it with `flatpak install --user OpenPax-0.1.9-linux-x64.flatpak`, then start OpenPax from the menu. Updates come through the game, your software center or `flatpak update`.
     - `OpenPax-0.1.9-linux-x64.tar.gz`: unpack it and run `./openpax`. This one updates itself.
   - **macOS (Apple Silicon):** `OpenPax-0.1.9-osx-arm64.tar.gz`. Run `./prepare_mac.sh` once from the unpacked folder, then open `OpenPax.app`.
2. On first start, point OpenPax at your copy of the game: an installed copy, or GOG's **offline backup installer** (`setup_pax_imperia_2.0.0.12.exe`). The small GOG Galaxy installer holds none of the game.
3. The import converts the game once, into your user folder (a few minutes). Then the game starts.
