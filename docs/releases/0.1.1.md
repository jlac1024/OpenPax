A small update to the first release of OpenPax, an open-source engine for Pax Imperia: Eminent Domain. OpenPax comes with **none of the game**: you need your own copy from [GOG](https://www.gog.com).

This is an early release: expect rough edges, and please report what you find.

## What's new in 0.1.1

- **Fixed: the first-run setup crashed when you pressed IMPORT** on some machines. The screen could ask for the import's progress before the import had reported any.
- **Crash reports.** If OpenPax stops unexpectedly, it now says why in an error box and writes the details to `crash.log` in your user folder, instead of closing with no word. Everything the game prints goes to `openpax.log` beside it, including the import's progress. On Windows that folder is `%APPDATA%\OpenPax\OpenPax\`. Please attach both files when you report a problem.
- The bundles now carry their version number, so logs say which release they came from.

Everything else is as in [0.1.0](https://github.com/jlac1024/OpenPax/releases/tag/v0.1.0); its notes cover what's in OpenPax and how to start.

## Getting started

1. Download the bundle for your system below and unpack it.
   - **Windows:** `OpenPax-0.1.1-win-x64.zip`. Unzip the whole folder, then run `openpax.exe`. Windows warns about an unsigned program: click **More info**, then **Run anyway**.
   - **Linux:** `OpenPax-0.1.1-linux-x64.tar.gz`, then run `./openpax`.
   - **macOS (Apple Silicon):** `OpenPax-0.1.1-osx-arm64.tar.gz`. Run `./prepare_mac.sh` once from the unpacked folder, then open `OpenPax.app`.
2. On first start, point OpenPax at your copy of the game: an installed copy, or GOG's **offline backup installer** (`setup_pax_imperia_2.0.0.12.exe`). The small GOG Galaxy installer holds none of the game.
3. The import converts the game once, into your user folder (a few minutes). Then the game starts.
