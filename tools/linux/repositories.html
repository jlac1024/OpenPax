OpenPax packages

Version @VERSION@. OpenPax is a new engine for Pax Imperia: Eminent Domain; it comes with none of the game, and plays your own copy from GOG.

These repositories let your system keep OpenPax up to date, as it does your other software. The easiest way in is to install a package from the releases page once: the .flatpak and the .deb both set up their repository themselves.

Flatpak

Install the release's .flatpak, or add this repository and install from it:

flatpak remote-add --user --if-not-exists openpax @URL@/flatpak/openpax.flatpakrepo
flatpak install --user openpax io.github.jlac1024.OpenPax

Updates then come through your software center, or flatpak update.

Debian, Ubuntu, Mint

Install the release's .deb from the folder you downloaded it to:

sudo apt install ./openpax_@VERSION@_amd64.deb

Or add the repository by hand, one command at a time:

curl -fsSL @URL@/openpax-signing-key.asc | sudo gpg --dearmor -o /usr/share/keyrings/openpax-archive-keyring.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/openpax-archive-keyring.gpg] @URL@/apt stable main" | sudo tee /etc/apt/sources.list.d/openpax.list
sudo apt update
sudo apt install openpax

Updates then come with your system's updates (Software Updater, or sudo apt update && sudo apt upgrade).
